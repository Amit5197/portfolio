# 🚀 Running Locally


Clone repository:


```bash
git clone https://github.com/YOUR_USERNAME/devops-portfolio.git
```


Go inside project:


```bash
cd devops-portfolio
```


Run:


```bash
open index.html
```


or use VS Code Live Server.


---

# 🐳 Docker Deployment


Create Docker image:


```bash
docker build -t devops-portfolio .
```


Run container:


```bash
docker run -p 8080:80 devops-portfolio
```


Access:


```
http://localhost:8080
```
